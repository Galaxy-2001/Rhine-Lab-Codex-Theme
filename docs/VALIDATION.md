**Windows 性能采样。** 在实际窗口切页期间，用 Windows 进程与 GPU 引擎计数器采样本次官方客户端进程树。CPU 按逻辑处理器数归一化，GPU 取同一引擎内各进程合计后的最高值。空白动画页的 15 个 CPU 样本平均为 3.82%，8 个 GPU 样本最高为 2%。有消息的对话页 5 个 CPU 样本平均为 1.36%，3 个 GPU 样本最高为 0%。这是本机短时观察，切页与前后台变化会影响读数。持续流式输出的帧率未测定。

**补充夹具与仍未实机的范围。** 1920 和 2560 CSS px 在独立 Edge 夹具中均无横向溢出，网格铺到边缘，刻度区域与输入框留有间隔。官方客户端本轮自动记录的最大布局宽度为 1707 CSS px。托盘忙碌时禁用菜单和更新提示、失败后恢复、成功恢复回调退出消息循环，均以本次编译的管理器和隔离 WinForms 控件验证。真实系统失败通知及恢复后退出仍未实机验证，后者须在不承载当前对话的主题会话里执行。实机局部截图和采样保存在本机忽略目录 `.checks/windows-live-20261118/`。

**先前 Linux 夹具结果。** 无头 Chrome 通过 10 项回归。交接记录中的 1680×1000 软件渲染测量为：空白页动画从 10–16 fps 提升到 60 fps，对话空闲主线程占用约 0.5%，单次刷新从约 13.5 ms 降到 0.08 ms，模拟 5 秒流式输出从约 105 段增至 294 段。这些数值只对应该夹具和测量环境。
