# 中央标志动画（2026-10-09，Codex 1.1.0）

参考《明日方舟》特别映像 [莱茵生命：访问] 03:50–04:04：
https://www.bilibili.com/video/BV1rr4y1b7sz/

聊天页的大标志从右边改为中央背景，使用 14 秒循环：米色折片环自转、折片压平并淡化为平面标志、平面标志的缺口沿轮廓循环，再回到折片环。立体和平面阶段由同一条中心曲线构建，消除之前使用另一条双环曲线造成的比例跳变。折片具有三维截面，绕局部切线自转；单一米色材质的明暗由表面法线、固定光源、镜面高光及三条采样光线的遮挡计算产生，随后预计算为 SVG 路径与颜色动画。它不是简单按折片序号交替填色，也不是旋转整个平面标志。

正号在左环中心从零放大，同时旋转 90° 到位。减号从右环中心的一条细竖线横向展开，高度保持不变。两者的入场衔接于折片压平阶段。

浅色使用米色折片和白色标志，深色降低亮度。此动画是用代码重制的矢量效果，不是原视频剪辑，也不能保证逐帧一致。侧栏标志保持原有动画。

生成源：`scripts/generate-watermark.mjs` 和 `scripts/ribbon-geometry.mjs`。所有动态/静态 SVG 均可由生成脚本生成，无须三维渲染库或额外下载素材。关闭主题动画或系统启用减少动态效果时，显示静态平面标志。

聊天页仅修改 background-size/background-position。实际 Codex 26.1002.7124.0 深色窗口修改前后，聊天主容器、输入编辑器和侧栏的 DOM 矩形一致。客户端成功载入新的 SVG 背景；动画引擎继续监控当前已验证的官方会话，未关闭客户端。浏览器检查覆盖浅深色、折片和平面阶段、减少动画、420/1280 像素窗口和输入框位置。额外检查将三维中心曲线与浏览器的 SVG 原生曲线逐点对照，误差小于 0.1 像素；验证了压平后所有顶点深度为零、旋转同时改变几何和光照、折片存在投射遮挡阴影，以及正负号入场过程中固定中心和变化矩阵。

已同步本机安装目录、Skill 随附运行时及 Git 源码。随 Codex 1.1.0 发布。DSH 1.1.2 仅包含提示文字对比度修复，未包含本动画。
