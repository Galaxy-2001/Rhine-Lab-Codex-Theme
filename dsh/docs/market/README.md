# 插件市场截图

首图 `sidebar-1.3.2.png` 以发布皮肤和皮肤中心的 CSS 转换器绘制。四栏对照浅色、深色的短列表和长列表，行内使用示例会话名称。

1.3.1 的首图 watermarks-1.3.1.png 由正式皮肤的 CSS 转换器与发布素材绘制，展示浅深模式下欢迎、对话和设置的背景。后续的实机截图对应 DeepSeek Harness 主题 **1.3.0**，来自官方 Windows 0.2.1-rc.3 客户端实录，包含浅色、深色及两种模式下的实际设置页。头像已替换为通用图标，账户与费用已遮盖。

市场图片清单位于 [`dsh/screenshots.json`](../../screenshots.json)，市场构建时从插件仓库读取；详细介绍读取 [`dsh/README.md`](../../README.md)。各版新图文件名带有对应版本号，与旧版示意图使用不同地址。市场仓库的下载条目需要单独更新，发布 GitHub Release 不会自动改写其中固定的 tarball URL。

本目录保留的 `1.2.1` 图片为历史素材预览，不是本次实机截图。`scripts/render-doc-previews.mjs --market` 生成的是旧版示意布局，不能用其输出替换当前实机图。
