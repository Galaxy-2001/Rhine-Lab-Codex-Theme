## 已验证

发布版加载器接受 v2 清单，CSS 转换与 token 审核没有警告。素材引用、安装目标和备份由七项自动测试检查。重复安装保留原来的皮肤选择；显式激活保留背景控制和未知配置字段；无效的现有状态文件会阻止激活写入。

将发布 TGZ 通过普通 `dsh plugin` 命令安装到全新的隔离 profile，确认只安装主题插件即可带入皮肤中心，并在首次启动自动选中莱茵生命。该 profile 的背景、设置页、深浅切换、恢复默认、刷新保存和移动视口检查全部通过，主题资源没有失败请求。自动测试还确认后续启动和主题包更新保留用户已经修改的选择。

实际网页端可以加载莱茵生命、恢复官方默认、重新应用主题，刷新后仍保留主题和深浅选择。浅色与深色的聊天、侧栏、设置弹窗均显示对应素材。预览图来自这次空白工作区实测。

通过官方桌面版“插件 → 添加插件”安装本地 TGZ，再点击“立即启用”，确认插件和依赖加载。实际浅色聊天页显示 RHINE LAB / HARNESS、STRU 与橙色标志，设置弹窗深浅两种配色均显示对应水印。修正 Windows 标题栏样式下整帧的侧栏底色遮挡；仅调整绘制，不修改布局尺寸。既有费用、推理强度与桌面宠物插件仍启用。

最终 1.1.1 TGZ 已在官方桌面客户端安装并启用。通过应用菜单完全退出后从官方应用入口重新打开，插件版本、主题水印与浅色选择仍保留。网页隔离 profile 安装同一最终 TGZ 后的回归检查也通过。

同一视口下，原生与主题的输入区域边界完全相同：x=498.09375、y=501、width=872.796875、height=52。背景没有增加聊天或输入框的占位。移动视口的文档宽度为 390，与视口相同，没有新增横向滚动。

预览图和深浅背景的资源请求均返回 HTTP 200。SVG 缺口的动画周期为六秒，连续采样确认缺口在移动；启用“减少动态效果”后动画名称为 `none`，连续采样位置不变。
